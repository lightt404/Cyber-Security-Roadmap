The path

Follow the phases in order. Phases 0 to 2 are for everyone; the track comes after.

0

Foundations

Weeks 1 to 8

Networking

  • OSI and TCP/IP models, IPv4/IPv6, subnetting, NAT
  • DNS, DHCP, HTTP/HTTPS, TLS handshake, ARP, ICMP
  • Ports, firewalls, VPNs, proxies, packet capture with Wireshark

Operating systems

  • Linux: filesystem layout, permissions, users and groups, processes, services, cron, package managers
  • Windows: registry, services, Active Directory basics, PowerShell

Programming

  • Python: files, sockets, requests, regex, writing small scanners and parsers
  • Bash scripting and one-liners (grep, awk, sed, cut)
  • SQL basics, plus reading simple JavaScript and PHP
  • Git and GitHub from day one

Resources

  • Professor Messer Network+ videos (free), Cisco Networking Academy intro courses
  • OverTheWire "Bandit", Linux Journey, TryHackMe "Pre Security" path
  • Automate the Boring Stuff with Python (free online)
Move on when you can: explain what happens when you type a URL into a browser, finish Bandit to level 15 or so, and write a Python script that reads a log file and counts failed logins.
1

Security fundamentals

Weeks 9 to 16

Core concepts

  • CIA triad, threats vs vulnerabilities vs risk, defense in depth, least privilege
  • Cryptography: symmetric/asymmetric, hashing, salting, digital signatures, PKI and certificates
  • Authentication: passwords, MFA, OAuth, JWT, session handling
  • Common attacks: phishing, malware types, MITM, DoS, SQL injection, XSS, CSRF

Frameworks to know by name

  • OWASP Top 10, MITRE ATT&CK, NIST CSF, CVE and CVSS

Resources

  • TryHackMe "Jr Penetration Tester" or "Cyber Defense" intro rooms
  • Google Cybersecurity Certificate (Coursera), Security+ study material
  • PortSwigger Web Security Academy (free): start with SQLi, XSS, authentication
Move on when you can: explain the OWASP Top 10 in plain words, demonstrate one SQL injection and one XSS on a practice target, and describe how HTTPS protects a login.
2

Hands-on practice

Month 4 onward, never stops

Build a home lab

  • VirtualBox or VMware with Kali Linux, plus targets: Metasploitable, DVWA, OWASP Juice Shop, VulnHub machines
  • A Windows VM and a small Active Directory lab for later red/blue work
  • Install Wazuh or Security Onion and watch your own attacks appear in the logs

Platforms and CTFs

  • TryHackMe learning paths, Hack The Box Academy and starting-point machines
  • picoCTF, CTFtime events, college and national CTFs (play in a team)
  • Tools to learn properly: Nmap, Burp Suite, Wireshark, ffuf/gobuster, John/Hashcat, CyberChef

Habit

  • Write a short write-up after every machine or CTF challenge: what you tried, what failed, what worked
Move on when you have: 30+ completed rooms or challenges, 5+ write-ups published, and at least one CTF played end to end.
3

Specialize in a track

Months 6 to 10

Pick one track from the next section and go deep. Keep spending a few hours a week on general practice so your base stays sharp.

4

Prove it

Months 9 to 12
  • Two or three portfolio projects on GitHub with clear READMEs
  • One certification matched to your track (see below)
  • A tidy LinkedIn profile and a one-page resume built around projects, labs, and CTF results
  • Internship applications, security meetups, and responsible bug bounty on programs that allow beginners

Choose a track

Not sure yet? Try a week of each: one pentest room, one SOC room, one GRC reading. Notice what you lose track of time doing.

Red team / pentesting

Attack to find weaknesses

Learn: recon, web app testing, privilege escalation, Active Directory attacks, reporting.

Tools: Nmap, Burp Suite, Metasploit, BloodHound, Impacket.

Project: a full pentest report on a HTB or VulnHub machine.

Blue team / SOC

Detect and respond

Learn: log analysis, alert triage, incident response steps, threat hunting, MITRE ATT&CK mapping.

Tools: Splunk, Wazuh, ELK, Sysmon, Sigma rules.

Project: a home SIEM that detects your own attacks, with custom rules.

GRC

Policy, risk, compliance

Learn: risk assessment, ISO 27001, NIST, audit process, India's DPDP Act and IT Act basics.

Tools: risk registers, policy templates, control mapping sheets.

Project: a mock risk assessment and policy set for a small organization.

AppSec / cloud

Secure code and infrastructure

Learn: secure coding, code review, API security, IAM, container and cloud misconfigurations.

Tools: Semgrep, OWASP ZAP, Trivy, AWS or Azure free tier.

Project: secure a small web app and document each fix.

DFIR / malware

Investigate and analyze

Learn: disk and memory forensics, timeline analysis, static and dynamic malware analysis, assembly basics.

Tools: Autopsy, Volatility, Ghidra, any.run-style sandboxes.

Project: an investigation report on a public forensic image.

AI security

Emerging, builds on any track

Learn: prompt injection, jailbreaks, data poisoning, model theft, securing LLM apps, OWASP Top 10 for LLMs.

Tools: Garak, PyRIT, Gandalf-style challenges, Python ML basics.

Project: test a small LLM app and write up its weaknesses and fixes.

Habits & rules

  • Legal and ethical only. Practice on your own lab or on platforms that give permission. Unauthorized access is a crime under India's Information Technology Act, 2000.
  • Report responsibly. If you find a real vulnerability, use the organization's disclosure channel or CERT-In rather than testing further.
  • Be consistent. One hour a day beats a weekend binge.
  • Write things down. Notes and write-ups turn practice into a portfolio.
  • Teach others. Run a session or explain a room to a friend; you will find your own gaps fast.
  • Join a community. Club sessions, local meetups, and CTF teams keep you motivated and get you referrals.
